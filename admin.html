Banners de la web

Gestiona el popup de bienvenida y el banner fijo de portada: cambia imágenes, enlaces, el orden, o desactívalos — sin tocar código.

Demo: los cambios se guardan en este navegador para que pruebes la experiencia. En la web final este panel se gestionará desde el back-office de PrestaShop que ya conocéis, y los cambios serán visibles para todos los clientes.

Popup de bienvenida

Una sola imagen. Se muestra una vez al entrar en la web y el cliente puede cerrarla.

Banner fijo de portada

Se muestra siempre en la portada, no se puede cerrar. Puedes añadir varias imágenes.
